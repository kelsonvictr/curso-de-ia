01 · teoria + fluxo

O que transforma um chat num agente

O modelo é o mesmo do Capítulo 1: ele continua prevendo texto. A diferença é que, no agente, parte desse texto são ordens para ferramentas: "abrir este arquivo", "criar aquele", "rodar este comando". O programa em volta do modelo executa a ferramenta e devolve o resultado para a conversa. E o ciclo recomeça.

🧠 O modelo

Decide o próximo passo, escrevendo. É o mesmo "cérebro" dos chats.

🧰 As ferramentas

Ler arquivo, listar pasta, criar, editar, rodar comando, buscar na web.

✋ As permissões

O freio de mão: o que ele pode fazer sozinho e o que precisa do seu ok.

🧑‍💼
Pense num estagiário muito rápido

Ele lê tudo, trabalha em segundos e nunca reclama. Mas é o primeiro dia: não conhece a empresa e, se você não disser, pode fazer algo que você não queria. Por isso ele mostra o plano e pede licença. Onde a comparação falha: ele não aprende sozinho de um dia para o outro. Nos próximos capítulos você vê como deixar as regras escritas para ele.

04 · prática guiada · 35 min

Prática A · Instalando o Claude Code pelo aplicativo

Sem terminal. O app Claude já traz o Claude Code dentro, na aba Code.

O que você vai precisar
  • Notebook com Windows ou macOS (tablet e Chromebook não servem)
  • Conta no Claude com plano pago (o Pro é o de entrada): claude.com/pricing
  • Uns 10 minutos de internet boa
  1. Baixe o app.
    ⬇ Windows ⬇ macOS
    Windows com processador ARM tem instalador próprio na página oficial de download.
  2. Instale e entre com a sua conta. No Windows, abra pelo menu Iniciar; no Mac, pela pasta Aplicativos. Faça login com a mesma conta do plano.
  3. Clique na aba Code, no topo. Se aparecer um convite para assinar, o plano ainda não está ativo nessa conta.
  4. Se o Windows pedir o Git, instale em git-scm.com avançando com as opções padrão, feche e reabra o app. É um ajudante de bastidores que você vai usar no Capítulo 6 como “máquina do tempo”.
  5. Confira o modo de permissão. Na linha abaixo da caixa de texto há um seletor. Use Manual durante o curso: ele pergunta antes de editar ou rodar qualquer coisa.
Manualpergunta antes de editar ou rodar. Use no curso.
Plansó planeja, não mexe em nada. Bom para tarefas grandes.
Accept editsaplica edições sem perguntar; você revisa depois.
Autoum verificador decide o que é arriscado. Para quem já tem prática.

Ainda sem pasta nenhuma, só para ver que está vivo:

Deu errado? Está previsto

A aba Code pede para assinar

O plano pago não está nessa conta. Confira em claude.ai, nas configurações da conta, qual plano está ativo, e se você entrou no app com o mesmo e-mail.

Pediu para entrar no navegador e voltou sem nada

Termine o login no navegador e reinicie o app. É o comportamento descrito na documentação oficial.

Windows reclamou de Git

Instale o Git em git-scm.com com as opções padrão e reabra o app.

Demorou muito para responder

A primeira resposta pode demorar um pouco. Se passar de um minuto, use o botão de parar e mande de novo.

05 · prática guiada · 25 min

Prática B · O kit da Aurora e a primeira conversa de verdade

O agente só enxerga a pasta que você abrir. Por isso, primeiro uma casa para o curso, depois o kit dentro dela.

O que você vai precisar
  • O app aberto na aba Code
  • O kit de treino da Aurora (arquivos fictícios)
⬇ Baixar o kit-aurora.zip
  1. Crie a casa. Em Documentos, crie uma pasta chamada curso-ia.
  2. Descompacte o kit dentro dela. Você deve ver curso-ia/kit-aurora/ com as pastas bagunca, contrato, declaracoes, marketing, planilha e professor.
  3. Abra a pasta certa no app. Na linha abaixo da caixa de texto: ambiente Local e, no controle de pasta, Open folder… escolhendo curso-ia/kit-aurora.
  4. Tarefa 1: só olhar. Ler não altera nada.
    👀 o diagnóstico da pasta da Marta
    dê uma olhada na pasta bagunca e me conte: quantos arquivos tem,
de quais tipos, e quais parecem duplicados. só olhe, não mude nada.
    o que deve aparecer (resumido) 34 arquivos: 15 imagens, 14 textos e planilhas (txt e csv), 5 PDFs. Prováveis duplicados: os três “relatorio final…”, as duas “anotações reunião”, “IMG_8274” e “cópia de IMG_8274”, os dois “logo-final-AGORA-VAI”.
  5. Tarefa 2: criar algo. Aqui ele vai pedir permissão.
    📝 o primeiro arquivo
    crie um arquivo diario.txt aqui na pasta com duas linhas: a data de
hoje e um resumo, em uma frase, do que você encontrou na pasta bagunca.
    o que deve aparecer (resumido) Pede permissão para criar diario.txt Criado. Abra a pasta kit-aurora e confira: o diario.txt está lá.
  6. Confira no seu explorador de arquivos. Abra o diario.txt. Esse é o momento “ele mexeu no meu computador de verdade”.
🧾
Por que essa pasta, e não Documentos inteira?

Abrir a pasta certa é o primeiro limite de segurança: o agente trabalha ali dentro. Para tarefas reais, abra só a pasta do assunto, nunca o computador todo.

07 · antes de ir

Kit de sobrevivência

🛑 Ele está indo pelo caminho errado

Aperte o botão de parar ou escreva a correção e envie. Não precisa esperar terminar.

🤔 Pediu uma permissão estranha

Recuse e pergunte: “para que você precisa disso?”. Recusar não quebra nada.

🧩 Apareceu código na tela

É o agente trabalhando. Você não precisa ler. Se quiser, peça: “explique em português o que você fez”.

📂 Ele não acha o arquivo

Quase sempre é a pasta errada aberta. Confira o controle de pasta abaixo da caixa de texto.

↩️ Não gostei do resultado

Peça para desfazer: “volte como estava antes”. No Capítulo 3 você aprende a pedir um relatório do que mudou para isso ficar fácil.

📝 Leve para o trabalho

Crie uma pasta com cópias de arquivos reais e sem dados sensíveis do seu trabalho e peça ao agente só para olhar: “o que tem aqui e o que você organizaria?”. Não deixe mexer ainda.

🧰 Antes do Capítulo 3

Deixe o app instalado e o kit aberto. Se a instalação travou, chegue 15 minutos antes que resolvemos juntos.
