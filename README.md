# Curso de IA — Programa AI

Material do curso presencial **Inteligência Artificial na Prática para Profissionais**: seis noites
para quem trabalha com planilha, contrato, e-mail e documento, de qualquer área, com o Claude Code
como ferramenta principal.

Abra `index.html` no navegador. Para testar áudio e vídeo, sirva a pasta:

```bash
python3 -m http.server 8840
```
